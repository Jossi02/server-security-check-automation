# Server Security Check Automation

2025년 대학 `네트워크보안` 수업에서 진행한 2인 팀 프로젝트입니다. 당시 KISA 「주요정보통신기반시설 기술적 취약점 분석·평가 상세 가이드」의 6개 항목을 Bash와 PowerShell로 구현했습니다.

> 이 저장소는 **historical course artifact + current mapping + retested behavior**를 공개하는 교육용 자료입니다. KISA 공식 도구가 아니며, 최신 가이드 전체 준수나 특정 운영체제의 보안 준수를 보증하지 않습니다. 조치 기능은 계정·서비스·정책·레지스트리·ACL을 변경할 수 있으므로 코드를 검토하고 disposable VM에서만 검증하세요.

## 항목 번호와 최신 가이드 매핑

기존 파일명 `U-52`, `U-57`, `U-61`, `W-50`, `W-62`, `W-71`은 수업 산출물의 역사성을 보존하기 위해 유지합니다. KISA가 2025-12-24 게시한 [최신 상세가이드](https://www.kisa.or.kr/2060204/form?postSeq=22)는 항목 번호와 구조가 달라졌으며, 통상 2026 가이드로 지칭됩니다.

| 기존 파일 | 2025 수업 당시 점검 내용 | 최신 대응 항목 | 공개본 처리 |
|---|---|---|---|
| `U-52.sh` | 동일 UID 계정 | `U-10` | 탐지 + 수동 조치 안내 |
| `U-57.sh` | 홈 디렉터리 소유자/권한 | `U-31` | 탐지 + 수동 조치 안내 |
| `U-61.sh` | FTP 활성화 | `U-54` 비암호화 FTP 비활성화와 개념상 가장 가까움 | 탐지 + 수동 조치 안내 |
| `W-50.ps1` | 최대 암호 사용 기간 | `W-09` 암호 관리 정책의 하위 요소 | 로컬 정책만 탐지·선택 조치·재조회 |
| `W-62.ps1` | SNMP 접근 통제 | `W-31` | 탐지 + 수동 조치 안내 |
| `W-71.ps1` | 이벤트 로그 파일 접근 제한 | `W-43` | 위험한 Allow ACE 탐지 + 수동 조치 안내 |

이 표는 항목의 의미상 대응 관계를 기록한 것이며, 스크립트가 최신 항목의 모든 판단 기준을 구현한다는 뜻이 아닙니다. 특히 `W-50.ps1`은 로컬 `net accounts`의 최대 암호 사용 기간만 확인하므로 도메인 정책이나 `W-09` 전체를 평가하지 않습니다.

## 처리 원칙

- 탐지 결과는 `PASS`, `FAIL`, `ERROR`로 구분합니다. 파싱·명령 실패를 취약으로 단정하지 않습니다.
- 자동 변경을 하지 않는 항목은 `MANUAL_REQUIRED`로 기록하며 `FAIL`이나 `fixed=true`로 위장하지 않습니다.
- 위험도가 큰 Linux 계정/서비스 변경, Windows 레지스트리/ACL 변경은 공개본에서 수동 조치로 제한했습니다.
- `W-50.ps1`만 관리자 확인, 백업, 명령 성공 여부, 실제 재조회 검증을 거쳐 로컬 정책을 선택적으로 변경합니다.
- 수업 당시 ATT&CK/TTP 메타데이터는 공개 시점에 재검증되지 않아 제거하거나 미검증 상태로 명시했습니다.

## 저장소 구조

```text
linux/                 # U-52, U-57, U-61
windows/               # W-50, W-62, W-71 및 W-50 파서
tests/                 # fixture 기반 비파괴 테스트
.github/workflows/     # 정적·비파괴 CI만 실행
docs/PROJECT_NOTES.md  # 공개 범위와 검증 기록
```

## 검증 현황

| 검증 | 대상 | 현황 |
|---|---|---|
| Bash 구문 검사 (`bash -n`) | `linux/*.sh`, `tests/*.sh` | 2026-08-29 통과 |
| PowerShell parser | `windows/*.ps1`, `tests/*.ps1` | 2026-08-29 통과 |
| Fixture 테스트 | U-52 UID 탐지, W-50 한/영 파싱 | 2026-08-29 통과 |
| ShellCheck | Bash 스크립트 | 2026-08-29 CI 통과 |
| PSScriptAnalyzer | PowerShell 스크립트 | 2026-08-29 CI 통과 |
| Linux 실제 조치 | 계정/권한/FTP 서비스 | 미실행 — disposable VM 필요 |
| Windows 실제 조치 | 로컬 암호 정책 | 미실행 — disposable VM 필요 |
| Windows 레지스트리/ACL 변경 | SNMP/Event Log | 공개본은 detect-only; 수동 검증 필요 |

CI는 실제 시스템 설정을 변경하지 않습니다. 정적 검사와 fixture 입력에 대한 탐지/파싱만 수행합니다.

## 실행 예시

코드를 먼저 읽은 뒤 테스트 VM에서 실행하세요.

```bash
sudo bash ./linux/U-52.sh
```

```powershell
.\windows\W-50.ps1
```

결과는 각 플랫폼 디렉터리 아래 `KISA_LOG/`, `KISA_RESULT/`, `KISA_BACKUP/`에 생성되며 Git에서 제외됩니다.

## 기여와 AI 활용

이 프로젝트는 2인 팀으로 진행했습니다. 저장소 소유자는 6개 점검 스크립트 중 대부분의 구현, Linux/Windows 공통 흐름과 출력 형식 정리, 보고서 공동 작성, 최종 발표자료 제작에 참여했습니다. 구현 과정에서 생성형 AI를 코드 초안·수정·검토의 보조 도구로 사용하고 프로젝트 요구사항에 맞게 통합했습니다.

모든 구현을 단독으로 수행한 프로젝트는 아닙니다. 팀 프로젝트 결과물의 공개에 대해 팀원의 동의를 받았으며, 이름·학번이 포함된 원본 보고서와 발표자료는 제외했습니다. 별도 라이선스는 부여하지 않았습니다.
