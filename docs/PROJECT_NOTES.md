# Project Notes

## 공개용 정리 원칙

이 저장소는 2025년 네트워크보안 수업 팀 프로젝트 결과물에서 소스 코드만 선별하여 공개하기 위한 정리본이다.

- 원본 보고서와 PPT는 팀원 이름, 학번 등 과제 제출용 개인정보가 포함되어 있어 제외했다.
- 소스 코드에는 API Key, 토큰, 비밀번호 등 명시적인 비밀정보가 포함되어 있지 않은지 공개 전 문자열 검색을 수행했다.
- `/etc/passwd`와 같은 문자열은 실제 자격증명 값이 아니라 운영체제의 시스템 파일 경로다.
- 실행 중 생성되는 로그·결과·백업 디렉터리는 `.gitignore`에서 제외한다.

## 작성자 기여 범위

본 프로젝트는 2인 팀 프로젝트이며, 저장소 소유자의 주요 기여는 다음과 같다.

- 점검 스크립트 대부분 구현
- 각 스크립트의 공통 형식과 실행 흐름 표준화
- 보고서 공동 작성
- 최종 발표자료 제작
- 코드 구현 과정에서 생성형 AI를 보조 도구로 사용

정확한 파일별 단독 저작 여부를 명시하지 않았으므로, 공동 프로젝트 결과물의 공개에 대해 팀원의 동의를 확인했으며, 개인정보가 포함된 원본 보고서와 발표자료는 공개 대상에서 제외하였다.
